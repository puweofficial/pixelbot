## How to Install PixelBot v3.0.0

1. Extract the ZIP file to a folder on your computer.
2. Open your browser (for example, Opera or Google Chrome).
3. Open the Extensions page and enable Developer Mode.
4. Click Load unpacked.
5. Browse to the extracted PixelBot folder and select the `select-this-in-chrome-extensions` folder.
6. Click Select Folder (or Open) to finish installing the extension.
7. Done, open some canvas site and you should see PixelBot UI with blue-purple gradient theme.

## Features

- Auto-place pixels on Pixelya and Pixmap
- Blue-purple gradient theme
- Telegram and Discord notifications for captcha events
- Error handling and automatic reconnection
- Queue-based pixel placement system
- Rate limiting to avoid detection

## Configuration

Click the extension icon to configure:
- Telegram Bot API token and Chat ID
- Discord Webhook URL and User ID

All credentials are encrypted and stored locally.
